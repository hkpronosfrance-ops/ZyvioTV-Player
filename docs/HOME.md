# Phase 5 — Home experience

## Goal

Replace the foundation placeholder with the first real streaming-home experience while keeping the ZYVIOTV black/red visual system.

## Android

The adaptive home now includes:

- hero area
- direct access to Live TV, Movies and Series
- Continue Watching shelf
- Live TV shelf
- Movies shelf
- Series shelf
- mobile bottom navigation with Accueil / TV / Films / Séries / Plus
- tablet/TV navigation rail through the existing adaptive shell
- automatic device sync remains active from Home

The cards are intentionally data placeholders at this stage. Real provider catalog data is connected in the Live TV, Movies and Series phases.

## iPhone / iPad

A native SwiftUI Home shell mirrors the same information hierarchy and brand direction.

## UX rule

The Home must remain usable before a full catalog has finished syncing. Sections will progressively populate from local cache/provider data rather than blocking the whole screen.
